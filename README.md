# Retail-E-Commerce — Patrones de diseño de software

Proyecto del curso de patrones de diseño: una tienda virtual en Python
(Flask + MySQL) que fue creciendo entrega a entrega, hasta llegar a un
**marketplace multivendedor** con patrones creacionales y estructurales.
